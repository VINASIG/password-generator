# Generator interaction review

The owner requested automatic generation, session visibility, text scramble, countdown, immediate regeneration and consistent VINASIG chrome on 7 October 2026. This intentionally replaces the original explicit-generation/masked-default policy. Cryptographic sampling, immutable vocabulary and fail-closed verification remain unchanged.

## Root causes and changes

The theme button omitted the shared theme-switch class and used a combined icon rather than the Sun/Moon pair. Its accessible name did not describe the target theme, and appearance did not persist like sibling tools. The footer lacked the localized homepage and website-information names. Both now follow the existing design-system source and appearance key. The only persisted value is light or dark, with no secret or generation preference stored.

The final settings disclosure has a bottom border, but the outer fieldset had zero margin and the generate control had no top margin. Generate now is placed immediately after the output with a 24 px gap. The result region comes first in reading and keyboard order. Narrow layouts show it above settings, while desktop keeps settings on the left and results on the right. The output previously inherited a transparent background and no border. Its dedicated canvas surface now has padding and a visible border in both themes.

Settings events previously cleared results without generating, reset show/hide on every generation and copied an unbounded textbox value into a clamping slider. A shared validation path now synchronizes accepted values, clamps upper bounds, and clears results for incomplete or malformed input. Lower bounds are applied on commit so entering a multi-digit number remains possible.

The first remote Linux run found that WebKit did not activate Pause during the pointer/focus/countdown fixture. A follow-up assertion confirmed the button remained unpressed immediately after the attempted click. Countdown updates replaced the label text node on every focus event and timer tick, including when the label was unchanged. The label is now only changed when its content differs, preserving the click target during focus. The fixture explicitly verifies the pressed state before advancing time. The failed v0.2.0 release run was cancelled; its signed tag is retained and does not stand for a published verified release.

## Automatic behavior

Generation occurs after verified startup, settings changes, Generate now and a 60-second active countdown. The duration is a product choice, not a cryptographic lifetime. Hover and selection freeze remaining time. Copy explicitly pauses rotation until resumed. Manual clearing stops rotation. Hidden-page/navigation cleanup cancels animation and both timers. Returning to a visible page creates a fresh result and preserves the volatile visibility preference.

Inactivity is tracked separately from generation. Automatic ticks cannot extend its five-minute deadline. A pending clipboard write or stale animation cannot resurrect an earlier revision. Decorative draws use Web Crypto independently of the final selection. The animated element is nonselectable and excluded from the accessibility tree, and Copy is unavailable until final text is ready. Reduced motion displays the final result immediately.

## Separator assessment

[Bitwarden generator documentation](https://bitwarden.com/help/generator/) allows a selected word separator. [Its CLI documentation](https://bitwarden.com/help/cli/) uses a hyphen by default. A space is also valid and adds no randomness. This version adopts hyphens while preserving the exact source lists.

EFF includes drop-down, felt-tip, t-shirt and yo-yo. None of their initial components is a separate EFF token. Consequently codewords consisting of each token followed by a hyphen are prefix-free. Greedy decoding is unique. The production plan verifies that property, and tests round-trip every EFF token paired with each compound. A synthetic vocabulary that collapses two different token tuples is rejected. Internal underscores are preserved for Vietnamese compounds.

## Evidence

Local checks include 25 unit/adversarial tests and a full run of 84 browser cases across Chromium, Firefox and WebKit, with zero failures, retries or skips. Responsive probes cover both languages and themes, 320 px, the declared viewports, breakpoint neighbors, 200 percent text, keyboard, forced colors and no JavaScript. A fixture draws the longest EFF token 20 times and checks that animation remains inside the output viewport and Generate now stays in place when the final text appears. Lifecycle cases also cover the first edit after an elapsed inactivity deadline. Screenshots of headers and footers before and after are retained in ignored output. The shared brand inspector's filename-only rule still requires the documented original-SVG byte check for embedded data URLs.

Raw before/after Lighthouse runs and environment records are retained under output/ux-review and output/performance. Actual medians and deployment results are recorded after they are observed. Physical-device, manual screen-reader and independent-review evidence is not implied by these automated cases.

The vocabulary message changes presentation rather than evidence. Concise usage guidance replaces repeated warnings in the form, while source pins, provenance, methodology and factual assurance records remain available. No data version, participant result or original release artifact is rewritten.
