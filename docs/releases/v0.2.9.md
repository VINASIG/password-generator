# v0.2.9

This research preview fixes configured result animation and interrupted tab use.

Password scramble frames use the selected character groups after exclusions and ambiguity removal. Passphrase frames use lowercase letters from the selected verified vocabulary while preserving separators, internal underscores and hyphens. The existing unbiased integer sampler supplies separate decorative draws. The completed secret, sampling algorithms, pinned wordlists and generation-space counts are unchanged.

Switching tabs or applications suspends rotation and removes plaintext and animation from the DOM. Returning before inactivity expiry restores the same volatile result and resumes its saved countdown, retaining manual pause and show/hide choices. It does not sample another secret or restart the animation. Hidden time counts toward the five-minute inactivity deadline, and actual page departure still clears the result. First entry from a background load generates once after integrity verification. Expired or invalid results remain cleared until a generation action or settings edit.

Masked password output also wraps within narrow WebKit viewports; the mask still has exactly one bullet per Unicode codepoint and copying preserves the selected secret text.

Regressions cover animation alphabets, exclusions, all character-group subsets, three vocabularies and separators, interrupted animation, countdown continuation and hidden inactivity expiry. The release requires successful Linux/Windows CI, matching cross-OS packages and build attestations. Automated verification and deployed observations remain separate from independent security review or participant evidence.
