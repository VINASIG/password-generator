# v0.2.8

This research preview adopts VINASIG's shared theme and language preferences under WEB-011. Appearance defaults to the operating system, with light as the unavailable-API fallback. The default-language entrypoint follows supported browser languages. Explicit theme/language choices use two finite Secure parent-domain cookies shared with the other VINASIG websites. There is no preference server, tracking identifier or secret storage.

Appearance changes update existing tabs without navigation. Language changes from another site navigate an untouched page while preserving tabs with trusted form, result, paste or drop interaction until their next load. Native locale links and offline pages remain available; blocked cookies use bounded local or volatile fallback. Original shared chrome/artwork, cryptographic sampling, wordlists and secret lifecycle are unchanged.

Source/CSP checks cover both embedded scripts. Three-engine actual-artifact tests exercise distinct HTTPS subdomains, system changes, manual overrides, protected input, legacy migration, malformed/duplicate cookies and denied storage. Local and deployed evidence remain separate. The release still requires exact-version notes, successful Linux/Windows CI, byte-identical packages and build attestations.

The CSP regression now submits a form to its own browsing context and waits for the actual script, connection and form policy events instead of assuming they arrive within 100 ms. The same blocked-behavior, navigation and response-header assertions remain required. Foreign-frame blocking retains its separate adversarial fixture. v0.2.7 did not pass the Windows publication gate and was not released; its tag is preserved unchanged.
