# v0.2.2

This research preview introduces automatic generation and consistent VINASIG chrome. Publication is gated on verification of this exact tagged revision. Earlier v0.2.0 and v0.2.1 release attempts did not publish: the first exposed a pause-control failure, and the second exposed a geometry fixture that confused focused-input scrolling with layout movement. Their signed tags remain unchanged. The pause label now preserves its click target, and geometry checks use document coordinates with recorded scroll offsets and unchanged one-pixel bounds.

## Behavior

- Generate after verified startup, relevant settings changes, a visible 60-second countdown and Generate now.
- Show results by default and preserve show/hide until reload.
- Animate visible results with a 480 ms character scramble, with cancellation, copy guards and reduced-motion support.
- Keep even a 20-word longest-token animation inside the output viewport, without moving Generate now when the final text appears.
- Freeze the countdown on result hover or selection. Copy pauses until resumed. Clear stops rotation. Automatic ticks never extend the five-minute inactivity deadline.
- Synchronize text inputs and sliders, clamp shared upper limits and clear stale results for incomplete input.
- Use shared Sun/Moon theme icons, localized accessible names, appearance-only persistence and consistent footer navigation.
- Give the output a separate surface, place Generate now with a 24 px gap and show results before settings on narrow screens.
- Default to hyphen-separated passphrases, preserving source spellings and verifying unique token decoding.
- Replace repeated vocabulary warnings in the form with concise usage guidance, while retaining original technical evidence and data identities.

## Validation scope

Uniform-selection, adversarial, Unicode, lifecycle, clipboard, privacy, CSP and artifact checks remain required. The browser suite covers the automatic interaction model in both languages and themes on Chromium, Firefox and WebKit. Publication requires the exact tagged revision to pass paired CI, byte-equal packaging and build-origin attestations. These automated checks do not imply an independent review or participant study.
