# v0.2.5

This research preview delivers the nine output-interaction corrections recorded in the [acceptance review](../UI-ACCEPTANCE-v0.2.4.md): full-width password wrapping, a visible 1.2-second scramble, adjacent Generate/Show/Hide/Copy actions, length-matched masking, exact native selected-text Copy, bold countdown seconds, contextual low-bit guidance, aligned translated metrics and concrete Vietnamese instructions. Cryptographic sampling, vocabulary, shared chrome and original font/brand assets are unchanged.

The v0.2.4 tag was held by failed CI and did not publish a release. Both Ubuntu executions retained 131 passes and one Firefox initial-navigation timeout waiting for the driver's load notification. The UI readiness fixture now waits for DOMContentLoaded, then separately requires document.readyState to be complete, the Copy control to be enabled, fonts to be ready and every image to decode. This replaces a driver notification with observable completion requirements; it does not waive page loading, relax geometry/behavior assertions, add retries or skip a browser. The precise intermittent driver cause remains undetermined. The signed v0.2.4 tag and failed logs are retained; no published artifact is replaced or historical tag rewritten.

This release requires a new exact-tag Ubuntu/Windows CI pair, byte-identical artifacts and build-origin attestations. The existing source-bound local evidence is supplemented by execution of the changed readiness fixture and the full tagged matrix. Deployment and affected live checks are recorded separately after completion.
