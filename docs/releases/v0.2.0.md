# v0.2.0

This research preview updates the generator interaction model and aligns its header and footer with the shared VINASIG tools.

## Behavior

- Generate on startup after integrity verification, whenever generation settings change and on a visible 60-second countdown. Generate now remains available.
- Show results by default. Keep show/hide until reload instead of resetting it on each generation.
- Animate new visible results with a 480 ms decorative character scramble. Respect reduced motion and cancel obsolete frames on hide, settings changes and lifecycle cleanup. Copy only the completed secret.
- Freeze the countdown on result hover or text selection. Copy pauses rotation until resumed. Clear stops rotation, and automatic ticks do not extend the five-minute inactivity deadline.
- Synchronize number fields and sliders, clamp upper bounds and reject incomplete input without returning a stale secret.
- Use shared Sun/Moon icons, localized target-theme names, appearance-only preference persistence and accessible footer names.
- Separate the output surface from its background and add spacing above Generate now.
- Use hyphens as the passphrase default. Preserve original EFF spellings and Vietnamese compounds. Verify prefix-free encoding before permitting hyphen serialization, including an ambiguous-vocabulary fixture.
- Replace repeated vocabulary warnings in product controls with concise representation and usage guidance. Original upstream evidence and data identities remain in the technical records.

## Validation scope

The existing uniform-selection, corruption, Unicode, fail-closed, CSP, privacy, clipboard and reproducible-artifact checks remain applicable. The expanded suite covers countdown, inactivity, visibility persistence, input regeneration, scramble cancellation, reduced motion, shared theme behavior, responsive layouts and output contrast. Release publication requires the exact tagged revision to pass paired CI, byte-equal packaging and build-origin attestations.

The preview channel and detailed assurance boundaries are unchanged. Publication records distinguish local tests, CI, delivered bytes and actual deployment rather than inferring one from another.
