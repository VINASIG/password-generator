# v0.1.0

This is a research preview of a static local password/passphrase generator. No independent security review, participant validation or production assurance is implied.

Passwords use Web Crypto and unbiased arbitrary-size rejection sampling. Optional composition requirements use exact completion counting and unranking over valid strings. Passphrases use the original EFF long list and unchanged, explicitly experimental Vietnamese Passphrase profiles. UI numbers describe generation space, not account security or a cracking-time promise.

Two languages, light/dark/forced-color controls and paired standalone HTML files share readable bundled code. There are no runtime packages, tracking, fetched lists, storage or service worker. Copy is explicit, masked secrets are absent from the DOM and lifecycle events clear page state. JavaScript, browser and clipboard erasure cannot be guaranteed.

The source and offline ZIPs have deterministic entry ordering and timestamps. Source pins, build records, automated adversarial and browser checks, license scopes and release verification instructions are included. Release attestations and environment records describe the actual published build when publication is authorized and successful. Local validation and prepared workflows must not be confused with executed CI.
