# v0.2.12

This research preview adopts the owner-approved Radix Gray interface appearance shared by VINASIG websites.

Both light and dark mode use neutral canvas, panels, fields, text and headings. Strong field outlines remain distinguishable from their adjacent surfaces. Progress and range indicators use derived VINASIG blues with a contrasting depleted track. Original identity artwork, fonts and wordlist bytes are preserved.

System appearance, shared manual theme and language preferences, local secret generation, animation settings and the interrupted-tab countdown retain their existing behavior. No runtime dependency, network request, secret storage or new telemetry is added. Source hashes are updated for the explicitly reviewed CSS adoption.

Release requires successful Linux and Windows CI, cross-OS byte equality and exact-tag build attestations. Browser checks cover both locales, appearance modes, animation, timers, clipboard, script failures and privacy restrictions. These are automated technical observations and remain separate from independent security review or participant evidence.
