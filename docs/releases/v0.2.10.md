# v0.2.10

This research preview delivers configured result animation and interrupted tab use, with a release-validation follow-up to the undeployed v0.2.9 tag.

Password scramble frames use the selected groups after exclusions and ambiguity removal. Passphrase frames use lowercase letters from the selected verified vocabulary while preserving separators and internal underscores/hyphens. Cosmetic draws use the existing unbiased sampler; secret sampling, lists and generation-space accounting are unchanged.

Switching tabs or applications pauses the remaining visible-time countdown and removes plaintext and animation from the DOM. Returning before the five-minute inactivity deadline restores the same volatile result, countdown, show/hide choice and manual pause state without new secret draws or animation. Hidden time still counts toward inactivity expiry. Actual page departure clears the session. First entry, including an initially background page, generates once after integrity verification. Narrow masked WebKit output wraps within its field.

Full v0.2.9 CI found an intermittent no-JavaScript Firefox navigation wait before assertions, despite a rendered HTTP 200 document. The preserved failure records are described in the acceptance review. The fixture now requires exact navigation, HTTP 200 and complete document readiness separately, retains its original assertions and adds disabled Copy/Reveal/settings and empty-output checks. Limits and retry policy are unchanged. The canceled rerun is not presented as evidence.

Release requires fresh successful Linux/Windows CI, cross-OS byte equality and build attestations. Automated validation and deployed observations remain distinct from independent security review and participant evidence.
