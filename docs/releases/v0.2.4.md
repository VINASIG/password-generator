# v0.2.4

This research preview fixes the output interactions reported after v0.2.3. The cryptographic sampling algorithms, pinned vocabulary, font and shared VINASIG chrome are unchanged.

- Password output fills each available line before wrapping, without adding newline characters to the generated value.
- The decorative scramble lasts 1.2 seconds and holds an initial 240 ms of scrambling so the first characters are visible in the animation, including at 128 characters. Reduced motion and interruption guards remain.
- Generate, Show/Hide and Copy form one adjacent action group. The redundant manual Clear button is removed; lifecycle and invalid-input cleanup remain.
- Hidden results display one bullet per Unicode codepoint. Native keyboard/browser Copy transfers the exact selected secret rather than the bullets. The Copy button still transfers the complete result. Synthetic Copy events cannot extract a secret.
- Countdown seconds are bold. Low-bit guidance sits beside the corresponding length or word-count controls. Translated metric values align even when labels occupy different numbers of lines.
- Vietnamese passphrase instructions now describe saving the password and trying a sign-in after setting it for the account.

The [acceptance review](../UI-ACCEPTANCE-v0.2.4.md) records the nine reported outcomes, before evidence, new regressions, revised product decisions and opened images. This release requires exact tagged CI, cross-OS artifact equality and build-origin attestations. Local behavior tests, visual observations, deployed checks and independent review are separate evidence classes.
