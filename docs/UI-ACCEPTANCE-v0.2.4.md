A real keyboard Copy followed by native Paste produces those bullets. The English metric-value top positions are 879.31, 856.92 and 856.92 px. Low-bit guidance belongs to the result column, away from the word-count shortcuts. Before images and observations are retained in `output/ux-review/v0.2.4/before/` and have been opened.

## Product decisions and test migration

Matching mask length replaces the intentionally fixed-length mask at the owner's explicit request. This changes visible length disclosure, not random selection. Selection offsets are mapped to codepoints only when masked, and to UTF-16 units when shown. A completed native Copy writes text only on a trusted browser event.

The owner requested a single result action group and questioned the Clear control. It is removed from the product UI, while all cleanup paths remain. Tests that invoked manual Clear now trigger invalid-input or pagehide cleanup and keep the same no-resurrection/no-rotation assertions. The new action inventory asserts absence of Clear. The initial render-to-action gap changes from the obsolete 24 px Generate separation to the requested 12 px unified group, retaining an upper spacing bound. Animation completion checks use 1,300 ms instead of 600 ms because the visible duration explicitly changes to 1,200 ms; interruption, copying and final-value assertions remain.
